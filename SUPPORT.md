# Getting help

Shipwatch is maintained on a best-effort basis. There is no support chat or
guaranteed response time.

1. Read the [documentation](docs/README.md), especially
   [troubleshooting](docs/troubleshooting.md).
2. Search [existing issues](https://github.com/mbianchidev/shipwatch/issues?q=is%3Aissue),
   including closed ones.
3. Still stuck? Open a [bug report or feature request](https://github.com/mbianchidev/shipwatch/issues/new/choose).
   Questions are welcome as issues too.

Report vulnerabilities privately through [SECURITY.md](SECURITY.md), never in a
public issue. Code of Conduct concerns go to the
[Code of Conduct contact](CODE_OF_CONDUCT.md#reporting-an-issue).
